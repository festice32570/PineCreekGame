# Pine Creek: 冬の町

![Pine Creek](godot/assets/ui/pine_creek_keyart.png)

雪に埋もれた架空の田舎町 **Pine Creek** を、古い架空のピックアップで走り回るAndroid向け3Dドライブゲームです。

> 人口は少ない。トラックは多い。常識は春まで雪の下。

巨大BBQ、埋まった除雪車、増殖する中古ピックアップ、役場を占拠する七面鳥ケビン、雪だるま市議会など、「住民だけは普通だと思っている変な日常」をゲームにしています。

## 現在の開発版

**v0.8.7-alpha1 — スポーン根治・圧雪サウンド修正版**

従来のJava + 自前OpenGL版からGodot 4.7.2へ移行した新物理版を継続開発しています。旧実装は比較・検証用として `app/` に残していますが、主開発は `godot/` です。

### v0.8.7-alpha1で変わったところ

- スポーンの根本原因を修正。メニュー中にfreezeされた車体へサスペンション力を蓄積しないよう変更
- 蓄積した力がゲーム開始時に一気に解放され、車体が上へ跳ねてから落下して見える問題を解消
- 車両は道路上の静止姿勢へ直接配置し、最初の運転入力までphysics lockを維持
- 圧雪音は速度でpitchを変えず、走行しても音階が上がらない方式へ変更
- 圧雪音そのものも、周期的なサイン波ベースから非周期の低周波タイヤ振動 + 短い雪クランチへ再生成
- フリー走行 / ストーリー両方で、初回入力後も車高がほぼ変わらないことを回帰QA

### v0.8.6-alpha1で変わったところ

- タイトルに「フリー走行」を正式追加。キャンペーン・目的地・アクション無しで町を自由に運転
- ストーリー選択中は運転タッチ入力を完全停止し、スクロールへ入力を渡すよう修正
- ストーリー一覧のドラッグ開始距離を短くしてAndroidでスクロールしやすく調整
- タイトル/ストーリー選択中はエンジン・雪路・スキッド・ホーンを完全停止
- スポーンは固定フレーム待ちだけでなく、車体速度と車高が安定した状態を連続10フレーム確認してから表示
- 表示直前に車体を再固定し、安定済み姿勢を1描画フレーム見せてから物理を解放
- 二重タップで複数の非同期スポーンが走らないよう開始ガードを追加
- 圧雪路音を通常速度で聞こえるレベルへ再ミックス

### v0.8.5-alpha1で変わったところ

- 3分フルテーマのコーラス16小節（25.6秒）をタイトル画面用ループとして実装
- ループの先頭/末尾を6msだけデジタルゼロへ落とし、音楽の拍を崩さずクリックを防止
- 圧雪路音から連続ホワイトノイズを廃止
- 雪上走行音を低いタイヤ/車体振動 + 圧雪が砕ける短い粒状音の6秒ループへ変更
- 雪上走行音の最大音量を抑え、V8エンジンが主役になるよう再ミックス
- タイトルループ長と新しい圧雪PCMループを回帰テスト

### v0.8.4-alpha1で変わったところ

- タイトル画面専用のオリジナル・ハードロック / ヘヴィメタル風テーマ曲を追加
- タイトル / ストーリー選択と通常走行でBGMを切り替える音楽コンテキストを実装
- 古いフルサイズピックアップ向けに720 RPM相当のV8燃焼パルス中心のエンジンループへ刷新
- エンジン音から連続ホワイトノイズ成分を除去
- 停車中の雪路音とスキッド音を-80 dBまでゲートし、「サー」というノイズ床を低減
- 走行中ラジオのハイハットも短いトランジェントだけにして連続ノイズを削減
- タイトルBGM / 走行BGMの切替と停車時ノイズゲートを回帰テスト

### v0.8.3-alpha1で変わったところ

- BGM / エンジン / 路面音の「ブチブチ」原因だった0-length loopを修正し、実サンプル数のloop_endを明示
- WAVを48 kHz / 16-bitのローカルPCMとしてインポートし、QOAデコードを避けてAndroid再生を単純化
- フレームごとの音声再スタート処理を廃止し、ループ音が連続再生されることを回帰テスト
- 復帰処理はRigidBodyを1 physics frame固定して道路へ移動し、復帰結果を確認して必要なら再試行
- Androidと同じ画面タッチ経路で「復帰」を押し、雪原から道路へ戻る実描画QAを追加

### v0.8.2-alpha1で変わったところ

- Masterバスを明示的に有効化し、BGMが停止していた場合に再開するランタイム保護を追加

### v0.8.1-alpha1で変わったところ

## 開発・ビルド

GitHub Actionsは必須ではありません。現在のGodot版は **Zorin OS / Linux上でローカルビルドして、そのAPKをReleaseへ公開する方式**を主にしています。

必要環境と手順は [docs/BUILD.md](docs/BUILD.md) を参照してください。

最短:

```bash
cd godot
./tools/qa_native.sh
./tools/build_android.sh
```

`qa_native.sh` は回帰テストと実描画スクリーンショットQAを実行します。
`build_android.sh` はテスト → release APK生成 → 署名検証 → package/version/SDK検証 → SHA-256生成まで行います。
