# Pine Creek: 冬の町

![Pine Creek key art](docs/pine_creek_keyart.jpg)

雪に埋もれた架空の田舎町 **Pine Creek** を、古い架空のピックアップで走り回るAndroid向け3Dドライブゲームです。

町の基本思想は単純です。

> 人口は少ない。トラックは多い。常識は春まで雪の下。

巨大BBQ、雪に埋まった除雪車、バッテリー上がり、「走れば車だ」中古車店、増殖するジムのトラック、役場を占拠する七面鳥ケビンなど、**普通の日常が少しずつおかしい田舎町**をテーマにしています。

## 現在のバージョン

**v0.6.2**

### ゲーム

- OpenGL ES 2.0による軽量3D描画
- 追従型3Dカメラ
- 前進 / ブレーキ / **バック走行**
- ホイールベースと操舵角を使った車両旋回
- 前進と後退で自然に反転するステアリング挙動
- 速度依存ステアリングとレート制御されたハンドル戻り
- 高速時の過敏な旋回を抑えるアーケード向け安定化
- 30 / 60 / 120 Hzで差が出にくい短周期の物理更新
- 圧雪路と深雪で異なる加速・抵抗・グリップ
- 最後に安全だった道路へ戻る「復帰」機能
- 旋回中は車両が先に画面内を左右へ動き、カメラ角度・横位置は遅れて追従
- 操作ボタンと会話メッセージの重なりを抑えたUI
- 添付キーアートをタイトル画面・アプリアイコン・GitHub Releaseへ使用
- 燃料 / 牽引 / 雪 / 街灯 / 住民
- ランダム町内放送 / 無線イベント
- 端末上でリアルタイム生成するBGM・風・エンジン・警笛・効果音
- セーブ / 続きから / 自由走行

## ストーリー

1. **初めての冬** — BBQ・除雪車・バッテリー救援・町民認定
2. **18台目のトラック** — ジムの庭から消えた18台目を追う
3. **ケビンの大脱走** — 七面鳥ケビン vs 町全体
4. **停電の夜** — 発電機と大量のブロックヒーター

詳しいストーリー案は [docs/STORIES.md](docs/STORIES.md) にあります。

## APKを入手する

普通に遊ぶだけなら **Releases** から最新版のAPKをダウンロードしてください。

**Releases → v0.6.2 → Assets → `PineCreek-v0.6.2.apk`**

AndroidでAPKを開けばインストールできます。

## 画像について

今回のキーアートは、提供された画像そのものを元にリサイズ・形式変換しています。

- タイトル / GitHubキーアート: 512×512 JPEG
- アプリアイコン: 192×192 PNG
- CIでは元ファイルのSHA-256と、APK内へ実際に格納された画像のSHA-256を比較

そのため、今後画像が壊れたり別データへ置き換わった場合はGitHub Actionsが失敗します。
