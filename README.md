# Pine Creek 3D v0.1

Android向けの小さな疑似3Dドライブゲームです。架空の雪国の町と架空のピックアップだけを使用しています。

## APKの作り方
1. このZIPを展開し、中身をGitHubリポジトリのルートへアップロードします。
2. GitHub Actionsを有効にします。
3. `Build Android APK` がpush時に自動実行されます（Actions画面から手動実行も可能）。
4. 成功後、RunのArtifactsにある `PineCreekGame-debug-apk` をダウンロードします。
5. ZIP内の `app-debug.apk` がインストール用APKです。

## 操作
横画面。左下が左右、右下がブレーキとアクセルです。

## Privacy
このプロジェクトは、依頼者の居住地・所有車・氏名などの個人的情報を含みません。舞台・車両・人物は架空です。
