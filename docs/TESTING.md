# Testing

Pine Creek v0.6.0では、車両挙動とAPK生成をGitHub Actionsで自動確認します。

## 自動テスト

`tools/VehiclePhysicsSelfTest.java` で次を確認しています。

- 停止中にハンドルだけで車体が回転しない
- 前進 + 左で正しい方向へ旋回する
- 前進 + 右で正しい方向へ旋回する
- バック + 左で車体のnoseとrearが物理的に矛盾しない
- ブレーキで前進からバックへ勝手に飛び越えない
- バック中のブレーキで前進へ飛び越えない
- 圧雪路で最高速上限を超えない
- 深雪が圧雪路より明確に遅い
- 牽引中の最高速制限
- ハンドルを離したときにセンターへ戻る
- 60 Hz / 120 Hzで速度・heading・位置が大きくズレない
- 30 Hz / 60 Hz / 120 Hzで旋回結果が大きくズレない
- バック最高速上限
- 深雪では圧雪路より旋回authorityが低い
- アクセルとバック同時押しで突然発進しない
- 1万stepのランダム入力でNaN / Infinityが発生しない

## Androidビルド検証

CIではさらに次を確認します。

- JDK 17
- Android SDK 35
- Gradle 8.11.1
- Android Gradle Plugin 8.9.2
- APK build成功
- `apksigner verify` 成功
- `aapt dump badging` 成功
- package名が `com.pinecreek.game`
- APKがArtifactとして取得可能

## 手動で確認したい項目

CIだけでは実際のタッチ感覚や端末GPUの見え方までは確認できません。

実機では特に以下を確認してください。

1. 低速で左右へ自然に曲がる
2. 高速でハンドルが過敏すぎない
3. バックで左右の挙動が直感に合う
4. 深雪で速度と旋回が落ちる
5. 牽引中に車が暴れすぎない
6. 建物へ衝突したあと極端に回転しない
7. 復帰ボタンで道路へ戻れる
8. カメラが旋回時にガクッと瞬間移動しない
9. 4本のストーリーが開始できる
10. 続きからで保存位置・進行が復元される

## 既知の限界

Pine Creekはフル物理エンジンを使ったシミュレータではありません。

現在の車両モデルは、スマホで遊びやすいアーケード挙動を狙った簡易bicycle modelです。

そのため、

- サスペンション物理
- 各タイヤごとの接地荷重
- 本格的な横滑り角
- 車体ロール / ピッチ
- 空力
- 路面の凹凸

などはまだ簡略化されています。

変な挙動を見つけたらIssue歓迎です。
