# Pine Creek Stories

Pine Creekの基本は「大事件ではなく、住民が真顔で処理する変な日常」です。犯罪・レース・バトル中心にはせず、雪・古い車・食べ物・町役場・ケビンが妙に大きな問題になります。

## Godot版で実装済み — 全24話

1. **BBQ小盛り非常事態** — この町の「小盛り」が本当に小さいのか確認する。
2. **町長と除雪車** — 除雪車を救うための除雪車が必要になった。
3. **ジムの18台目** — 17台だった車が一晩で18台になった。
4. **役場のケビン** — 七面鳥ケビンとの外交手段は警笛3回。
5. **郵便受けの冬季移住** — 郵便受けが除雪のたびに住所を変える。
6. **春の誤報** — +1℃だけで春祭りを始めた町を止める。
7. **公共交通が発生** — 荷台と折りたたみ椅子で町営バスが誕生。
8. **雪だるま市議会** — 議員不在なので雪だるまが定足数を満たす。
9. **凍った誕生日ケーキ** — 巨大ケーキを完全凍結前に届ける。
10. **非常事態レベル紫** — 町長のコーヒー切れは赤より上の非常事態。
11. **シカではありません** — 三時間動かないシカの正体を調べる。
12. **看板が旅に出た** — 町の入口看板が風で別住所へ転居した。
13. **ケビン給油所占拠** — ケビンが給油ノズル前で動かず燃料行政が停止。
14. **町内放送2014** — 12年前の町内放送が復活し住民が全部従い始める。
15. **ジムの19台目** — 18台目を数え終えた直後に19台目が出現。
16. **四月なのに一月** — 雪が残っているのでカレンダー故障説が有力になる。
17. **除雪車の追悼式** — 壊れたと思われた除雪車が式典中に普通に始動する。
18. **コーヒー氷河** — 屋外放置されたコーヒーが固体貨物になった。
19. **黄色い雪かき失踪** — 町で唯一の黄色い雪かきが消える。
20. **GPSが雪山を道路認定** — 配達員のGPSが雪山を最短ルートとして案内する。
21. **ボブの在庫監査** — 車21台に対して鍵が27本、書類が22台分ある。
22. **洗車機が凍った** — 洗車機のブラシが巨大な氷の彫刻になる。
23. **128日連続の雪予報** — 「明日は雪」を128日連続で当てるラジオ局。
24. **肉温計が公式気温** — BBQの肉温計が公共インフラになる。

## ストーリー選択

v0.8.0-alpha1からタイトル画面の「ストーリーを選ぶ」で全24話から任意に開始できます。
選んだエピソードをクリアすると次のエピソードへ進み、最終話後は町内事件がランダムに再発します。

## 追加方針

- 人物・場所・車両は架空
- 住民は妙な状況を妙だと思っていない
- 雪は敵というより町のインフラ
- 古い車は「走るなら現役」
- 食事量がおかしい
- ケビンは悪役ではなく天候に近い
- 会話・UI・パンチラインは日本語中心
- 実在人物や実在企業に依存しない
- 同じ目的地を往復するだけにならないよう、アクション・警笛・時間制限を混ぜる
