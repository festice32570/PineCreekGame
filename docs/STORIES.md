# Pine Creek Stories

このファイルは実装済みストーリーと、今後追加できるシナリオ案をまとめます。

## 実装済み

### 初めての冬

新しく町に来た主人公が、巨大BBQの配送からPine Creekの日常へ巻き込まれていく本編。

主な出来事:

- 巨大BBQ
- 町長が除雪車ごと埋まる
- 私物ピックアップで公共車両を救出
- バッテリー救援
- 「四月まで休憩中」のトラック
- ボブ中古車店「走れば車だ」
- ジムの17台目
- 役場を占拠する七面鳥ケビン
- 雪嵐の緊急BBQ便
- 町民認定

### 18台目のトラック

ジムの18台目が勝手に坂を下り、行方不明になる。

見つけて牽引し、バッテリーまで用意して戻すが、直後に19台目候補が現れる。

### ケビンの大脱走

七面鳥ケビンが食堂のパンを持って逃走。

食堂 → 給油所 → 中古車店 → 町役場と町中を移動し、警笛が重要な攻略手段になる。

### 停電の夜

町全体が停電。

大量のブロックヒーターが原因らしいが、まず発電機を牽引して食堂・給油所・立ち往生車・町役場を救援する。

復旧直後、さらに一台分のブロックヒーターが追加される。

## 今後の候補

### 春が来ない

四月になっても雪が残り、住民が「カレンダーの方が壊れた」と判断する。

### BBQ配達選手権

競争ではなく、誰が最も巨大な料理を無事に運べるかという町内行事。
道路上には雪山、放置トラック、ケビンがいる。

### ボブの在庫整理

中古車店の「在庫」を整理する。
問題は、ボブ自身も何台あるか知らないこと。

### ジムの庭を空けろ

消防点検のため通路を作る必要がある。
17台以上の車を移動するが、移動先も全部ジムの敷地。

### 町内放送が止まらない

放送設備が壊れ、過去数年分のお知らせがランダム再生される。
放送内容を手掛かりに修理部品を探す。

### ケビン対除雪車

ケビンが道路中央から動かない。
除雪担当は「鳥を避ける」「雪もどける」「トラックも避ける」を同時に要求される。

## ストーリー追加方針

- 犯罪や大規模アクションより「日常の妙なスケール感」
- 町の人は異常事態を異常だと思っていない
- 古い車は壊れていても引退扱いされない
- 雪は敵というより町の構成要素
- 食事量がおかしい
- ケビンは悪役ではなく自然災害に近い
- 英語に頼らず日本語で遊べる
