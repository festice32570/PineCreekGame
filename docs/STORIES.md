# Pine Creek Stories

Pine Creekの基本は「大事件ではなく、住民が真顔で処理する変な日常」です。犯罪・レース・バトル中心にはせず、雪・古い車・食べ物・町役場・ケビンが妙に大きな問題になります。

## Godot版で実装済み

### BBQ小盛り非常事態
BOB'S USED CARSで「小盛り」の意味を聞き、PINE CREEK FAMILY BBQへ向かう。小盛りでも皿から肉が落ちる。

### 町長と除雪車
町役場から公共事業ヤードへ。除雪車を助けるために除雪が必要という循環問題。

### ジムの18台目
17台目の話は昨日まで。今朝18台目になった。ボブは「売ってない、値札が付いてただけ」と主張する。

### 役場のケビン
七面鳥ケビンが正面玄関を占拠。警笛3回で交渉する。

### 郵便受けの冬季移住
除雪で郵便受けが数軒先まで移動。住民は「明日また移ったら本人の意思」と判断する。

### 春の誤報
+1℃表示で春祭りが始まりかけるが、温度計の下に排気管があることが発覚。祭りは中止、肉は中止できない。

### 公共交通が発生
ボブが荷台に折りたたみ椅子を置いて町営バスを名乗る。運行日はボブが起きた日。

### 雪だるま市議会
議員が来ないので雪だるまで定足数を満たす。異議は溶けるまで受け付けない。

## 次に追加したい事件

- **真夜中の鹿** — 緊急通報の正体は庭のプラスチック鹿
- **ケビン給油所占拠** — 給油ノズルの前から動かない
- **春が来ない** — 四月になっても雪なのでカレンダー故障説が有力になる
- **町内放送が止まらない** — 数年前の告知がランダム再生され、住民が全部従う
- **巨大誕生日ケーキ輸送** — 道路の段差で崩さず運ぶ
- **ボブの在庫整理** — 何台あるか本人も知らない
- **ジムの19台目** — 18台目の解決直後に増える
- **道路標識の冬季移住** — 風と除雪で町の入口標識が別の道へ行く

- ケビンは悪役ではなく天候に近い
