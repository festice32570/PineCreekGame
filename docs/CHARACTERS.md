# Pine Creek Character Design — Season 1

この文書はSeason 1で使う登場人物の**正式なビジュアル設計基準**です。

目的は、ゲーム内3Dモデル・会話ポートレート・ストーリー選択画面・GitHub紹介画像で同じ人物に見えるようにすることです。生成画像を最終素材の基準にはせず、Blender上の同一3Dモデルを一次ソースにします。

## 1. 全体アートディレクション

- 写実ではなく、少し角張った低ポリ3D
- 田舎の冬服でシルエットを強くする
- 顔の情報量は少なめだが、遠目でも人物が分かる
- 住民側は少し誇張、主人公だけ比較的まとも
- 「全員本人たちは真面目」というコメディに合う表情
- Androidの小さい画面でも読みやすい

雰囲気は「古い3Dアドベンチャーを現代の見やすさで作り直した」くらい。毛穴・髪の一本一本・布の微細なしわは作りません。

### 共通寸法

- 人間キャラ: 6.5〜7頭身
- 頭は現実より約8〜12%大きめ
- 手とブーツも少し大きめ
- 冬服の厚みをシルエットとして使う
- 足元は雪面で埋もれないよう靴底を厚めにする

### モバイル向け目標

- Body + clothes: 3,000〜5,500 triangles
- Hair / hat / props: 500〜1,500 triangles
- 合計: 6,500 triangles以下を基本
- Texture: 512x512 1枚、必要ならface用256x256を追加
- Material: 2〜4個程度
- Skeleton: 共通human rig
- BlendShapeは最小限。表情は主に眉・目・口・頭の角度で作る

背景NPCは1,500〜3,000 triangles程度を目標にします。

## 2. Pine Human Base

全員を別々にゼロから作らず、head / torso / arms / hands / legs / boots / eyes / mouth / eyebrowsを共通化します。

交換パーツ: hair、knit cap、work cap、winter hat、beard、jacket、work coat、reflective jacket、flannel、gloves、boots、glasses、key ring、tools。

共通アニメーション候補: idle、talk、nod、point、wave、arms_crossed、shrug、look_at_car、shovel、inspect_vehicle、carry_box。

## 3. 主人公

### 役割

Pine Creekの異常さを測る基準になる人物。住民よりデザインを抑え、最初は普通の人に見せます。シーズンが進むほど服や装備がPine Creek化します。

### 外見

- 日本から来た若い成人
- 身長目安: 1.74〜1.78m
- 標準〜やや細身
- 黒〜濃い茶の短い髪
- 髭なし
- 派手なアクセサリーなし
- 比較的きれいな冬用ジャケット
- 濃色パンツ
- 防寒靴だが作業靴ほどゴツくない

顔は「無表情でも少し困って見える」程度。大きく漫画的な目にはしません。

### Season 1での見た目変化

- 1〜3話: きれいなジャケット、普通の冬靴
- 4〜8話: 作業用手袋、少し雪汚れ
- 9〜12話: ニット帽、本格的なブーツ、小工具
- 13〜18話: 黒いセダンの鍵、ガレージ汚れ
- 19〜24話: 完全にPine Creek仕様。ただし本人だけ普通だと思っている

### ポートレート

neutral / confused / annoyed / resigned / tiny_smile

特に resigned は「もう突っ込むのも疲れた」という終盤の主人公に使います。

## 4. Bob

### 役割

最初にPine Creekの価値観をプレイヤーへ叩き込む人物。『IF IT RUNS, IT'S A CAR.』を本気で信じている。詐欺師ではなく、本人は本当に親切で合理的なつもり。

### 外見

- 40代後半〜50代くらいに見える
- 1.82〜1.86m程度
- 大柄、少し腹が出ている、肩幅が広い
- 短い無精髭
- 古いワークキャップ
- 分厚いワークジャケット
- フランネルシャツ
- 汚れた作業用グローブ
- 太めの防寒ブーツ

目標は「20年前から同じ上着を着ていそう」。シルエットは大きく四角い。

### 小物

大量の車の鍵、値札タグ、マグカップ、たまに工具。

### 表情

neutral_deadpan / confident / proud / thinking / almost_smile

大笑いさせず、異常な説明を真顔でする。

### 代表ポーズ

腕組み、親指で車を指す、ボンネットを軽く叩く、エンジン音を聞いてうなずく。

## 5. Jim

### 役割

Pine Creekの『機械は直せばまだ使える』を体現する人物。Bobより技術屋で、車が壊れているという概念をなかなか認めません。

### 外見

- 40代くらい
- 1.76〜1.80m
- 細身〜標準、少し猫背
- ニット帽
- 古い作業ジャケット
- パーカーまたはフランネル
- 片方だけ外した作業グローブ
- 作業パンツ
- 油汚れのあるブーツ

顔は少し疲れているが、車を見る時だけ姿勢が良くなる。

### 小物

レンチ、小型ライト、油染みのメモ帳、腰工具、たくさんの鍵。

### 表情

neutral / inspecting / mildly_impressed / absolutely_certain / confused_by_humans

## 6. Mayor

### 役割

Pine Creekの行政がなぜ機能しているのか分からない原因の一人。偉そうな政治家ではなく、『町の面倒事を全部自分でやる人』。

### 外見

- 50代後半〜60代くらい
- 1.70〜1.76m
- ややがっしり
- きちんとした冬用コート
- 下は作業パンツ
- ゴム長靴 / 防寒作業靴
- 必要な時だけ反射ベスト
- 防寒帽

遠目では町長、近づくと公共事業員にも見えるデザイン。

### 小物

大量の車の鍵、無線機、書類フォルダ、雪用スコップ、牽引ロープ。

### 表情

official_neutral / serious / satisfied / bureaucratic_thinking / tired_but_functional

## 7. Kevin

### 役割

町全体が真剣に扱う七面鳥。単なるマスコットではなく、意志が強いNPCとして見せます。

### 外見

- 現実の七面鳥より少しだけデフォルメ
- 体は丸め
- 脚は細めだが読みやすく太くする
- 尾羽を大きくしてシルエットを強くする
- 頭は少し大きめ
- 目もわずかに大きめ
- 色は自然な七面鳥の範囲

### 行動

人間を怖がるというより『面倒だから逃げる』。車を見ると首を傾げ、ホーンに反応し、荷台に勝手に乗り、役場へ入ろうとします。

### アニメーション

idle_peck / walk / run / look_left_right / horn_react / jump_into_bed / angry_flap / sit_in_truck_bed

Kevinだけは普通の会話ポートレートにせず、必要な時は真正面の無表情な七面鳥画像を使うと面白い。

## 8. シルエット比較

横一列に立たせた時:

- 主人公: 細め、整っている
- Bob: 大きく四角い
- Jim: 細く少し猫背
- Mayor: コートで縦長、足元は作業員
- Kevin: 低く丸い

全員を黒塗りにしても誰か分かることを目標にします。

## 9. 会話ポートレート仕様

- 512x512 PNG
- transparent background
- chest-up
- camera angle固定
- soft key light + weak fill
- 同じ焦点距離
- 顔サイズを揃える
- 過剰なDOFなし
- Godot側で名前・字幕と合成

人間主要キャラは最低5表情程度。

## 10. ストーリー一枚絵

一枚絵も同じ3D資産から作ります。第1章の候補:

1. 第1話 — Bobの中古車店、ボロい4WD、IF IT RUNS, IT'S A CAR.
2. 第3話 — 切れた牽引ロープを見下ろすJimと主人公
3. 第4話 — 荷台いっぱいのBBQ
4. 第5話 — Mayorの大型ピックアップが除雪
5. 第6話 — 荷台にKevin、周囲は全員真顔
